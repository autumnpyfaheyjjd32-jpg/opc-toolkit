# SKU-02 试用样张 · PPT 自检清单节选

这是《PPT 急救包》的免费样张。完整版含八步完整清单、A/B/C 问题分级、交付前文件 / 换机 / 内容终检三张表；这里放出问题分级、部分检查项和完整的 25 分钟修改顺序。

---

## 一、先判断问题等级

| 等级 | 判断标准 | 处理方式 |
| --- | --- | --- |
| A 必须先修 | 看不清、读不懂、页面错位、内容缺失、数据表达可能造成误解 | 演示前必须完成 |
| B 建议修复 | 风格不统一、重点不突出、图片模糊、图表难读 | 完成 A 级后集中处理 |
| C 有余力再改 | 装饰细节、轻微对齐差异、不影响理解的视觉优化 | 时间充足再处理 |

**先修 A，再修 B，C 可以不做。** 不要从第一页开始逐字润色。

---

## 二、检查项节选

### 1. 备份与全局扫描

- [ ] 已将原文件复制一份，并用“主题名称＋日期＋版本”命名修改稿。
- [ ] 已确认页数、演示时长、屏幕比例和提交格式符合实际要求。
- [ ] 已快速播放全部页面，记录错位、缺图、乱码、异常动画和打不开的链接。
- [ ] 已删除真正无用的重复页、空白页和测试页，但没有误删备用内容。

### 2. 版式与结构

- [ ] 一页只承担一个主要任务。
- [ ] 每页标题能够表达结论或问题，不只写“情况介绍”“数据分析”等空泛词。
- [ ] 同一层级的页面使用一致的标题位置、边距、页码位置和内容起始线。
- [ ] 页面四周留有稳定边距，文字、图表和图片没有贴边或越界。
- [ ] 内容过多时已删减、拆页或转为讲稿，没有为了塞下而过度缩小。

### 3. 字体与文字

- [ ] 全文主要字体控制在一至两种，同类内容使用同一字体规则。
- [ ] 标题、正文、注释之间有清楚的字号层级，正文在实际投影距离下可读。
- [ ] 正文段落已压缩为短句或要点，避免整页都是连续长段文字。
- [ ] 专有名词、姓名、日期、单位、百分号和大小写已核对。
- [ ] 没有用连续空格或回车强行对齐，文本框尺寸改变后版面仍基本稳定。

### 4. 配色

- [ ] 已确定一种主色、一种强调色和必要的中性色，没有每页随意换色。
- [ ] 背景与文字对比足够，浅色背景不用过浅文字，深色背景不用灰暗小字。
- [ ] 强调色只用于重点、状态或行动信息，不把整页所有内容都设为强调色。
- [ ] 关键信息不只依赖红绿差异，还配有文字、图标、线型或直接标签。

### 5. 图片与图表

- [ ] 图片与本页观点直接相关，不使用只占空间却不传递信息的装饰图。
- [ ] 图片在全屏下清晰，没有明显马赛克、拉伸、压扁或锯齿。
- [ ] 每张图表都有明确标题，观众能知道“看什么”和“得出什么结论”。
- [ ] 数据、单位、时间范围、口径和来源说明与实际材料一致，没有自行补造数值。
- [ ] 坐标轴起点、刻度和范围不会夸大差异；需要截断时已明确说明。

### 6. 交付前

- [ ] 已删除批注、隐藏测试内容、无关备注和不应交付的个人信息。
- [ ] 已导出 PDF 作为版式备份，并逐页抽查是否缺字、错页或变形。
- [ ] 已在另一台设备或另一款兼容软件中打开，确认字体、图片和图表没有明显错位。
- [ ] 已准备演示文件、PDF 备份和必要媒体文件，且存放位置容易找到。

## 三、25 分钟急救修改顺序（完整）

| 时间 | 只做这些事 | 完成标准 |
| --- | --- | --- |
| 0 至 3 分钟 | 复制备份，快速播放全稿，标出 A 级问题 | 已知道最严重的三类问题 |
| 3 至 9 分钟 | 修正页面顺序、标题、错位、越界和内容过载 | 每页主要任务清楚，文字不越界 |
| 9 至 14 分钟 | 统一字体、字号层级、行距和对齐 | 同级内容样式一致 |
| 14 至 18 分钟 | 统一主色和强调色，修复低对比文字 | 重点清楚，正文可读 |
| 18 至 22 分钟 | 替换模糊图片，核对图表标题、单位和标签 | 图片清晰，图表不误导 |
| 22 至 25 分钟 | 全屏播放，检查动画、链接、首尾页并导出 PDF | 文件能打开，备份可用 |

---

## 四、最终通过标准

四项同时满足才算完成：

1. 文件能够正常打开和重新保存。
2. 观众只看标题就能理解主要逻辑。
3. 文字、图片、图表在全屏下清楚且没有错位。
4. 数据、单位、来源、链接和媒体已经核对。

时间不足时，优先保证内容准确、结构清楚和现场可用；装饰细节留到下一版。
