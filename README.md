## 4 个 SKU

### SKU-01 · AI 提示词 121 套 · ¥9.9

7 个方向、121 套可直接复制的提示词，另附 6 份 Prompt / LLM / LangChain 学习资料。

- PPT 演示 18 套、办公文档 16 套、编程开发 20 套、营销增长 18 套
- 科研论文 16 套、数据分析 15 套、内容创作 18 套
- 每个方向一个 `.md` 文件，按编号连续排列，复制代码块即可使用
- 附分类目录：15 个文件逐条对账，含 3 个填好示例的完整样张
- 附买家说明：打开顺序、替换方法、授权边界

适合：经常写 PPT 大纲、周报、会议纪要、邮件的人；想让 AI 先出结构化初稿的人。
不适合：想要现成成稿或代做的人；想要“输入一句话就自动交付”的人。

### SKU-02 · PPT 急救包 · ¥19.9

一份可以边检查、边修改、边勾选的自检清单，覆盖课程汇报、答辩、路演、工作总结、客户提案。

- 按“备份 → 版式 → 字体 → 配色 → 图片 → 图表 → 演讲 → 交付”排序
- A / B / C 三级问题判定，先修影响理解的，再修装饰细节
- 25 分钟急救修改顺序表，时间不够时知道先做什么
- 交付前文件检查、换机检查、内容终检三张表

适合：明天就要讲、手上只有一版草稿的人。
不适合：想要现成 PPT 模板或代做整份演示的人。

### SKU-03 · OPC 接单工具箱 · ¥39

把“接一单活”从问价到验收的 6 个环节，做成可以直接改的文档模板。

- 一页交付清单
- 99 / 150 / 400 三档服务套餐与范围
- 下单前需求问卷
- 部署验收单
- 常见问题
- 客服回复草稿

适合：接远程部署、调试、文档整理、AI 工具落地类小单的人。
不适合：想要现成客户名单、流量或成交承诺的人。
